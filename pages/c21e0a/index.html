访问权限修饰符

#Java中四种访问修饰符

注意事项：Java的访问控制是停留在编译层的，也就是它不会在.class文件中留下任何的痕迹，只在编译的时候进行访问控制的检查。其实，通过反射的手段，是可以访问任何包下任何类中的成员，例如，访问类的私有成员也是可能的。

参考链接：Java基础：Java中四种访问修饰符 (opens new window)

# public 公有的

表示是公开的，任何类可以进行访问

# protected 受保护的

表示是受保护的，主要作用是用来保护子类，表示子类可以访问用它修饰的成员

# 作用域

  1. 声明为protected的方法和成员变量能被同一个包里的所有类所访问
  2. 父类仍然能调用子类对象继承的protected修饰的方法或者属性
  3. 子类不与父类在同包下,子类继承了的父类protected方法或属性,可以在子类的包中使用

# private 私有的

表示访问权只在本类内部，外部无法进行访问

# default

同一包中的类可以访问，声明时没有加修饰符，认为是friendly。

修饰符 类本身 同一个包下 子类 项目类路径下

default 1 1
protected 1 1 1
