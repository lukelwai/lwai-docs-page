    # 更换主题 vuepress-theme-vdoing

    因为原始的主题其实并不满足使用需求，展示的内容，存在一定的变形等问题，所以考虑之后决定更换一个主题

    1. 简单找了找决定更换这个主题：vuepress-theme-vdoing (opens new window)

    2. 第一步引入主题依赖

      npm install vuepress-theme-vdoing
      1

    3. 第二步，增加相应配置在config.js的配置中，增加一下配置，重新编译即可，其他的特殊配置可以查看主题的GitHub文档

      theme: 'vuepress-theme-vdoing'
      1
