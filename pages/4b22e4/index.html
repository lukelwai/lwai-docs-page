Linux服务器mysql之安全清理mysql-slow.log

一、需求说明
  服务器经过一段时间的运行，开发数据库的mysql-slow.log文件已经非常大了，为了释放磁盘空间，需要对该文件进行清理。mysql-slow.log文件是记录sql语句的执行时间超过设置的long_query_time 的语句，默认1秒钟，可以根据数据库实例进行调整设置。

二、处置步骤

  1. 检查慢日志参数配置，默认参数超过1秒钟的sql语句为进入慢日志。

    mysql> show variables like ‘%slow%’;
    1

  2. 关闭慢日志

    mysql> set global slow_query_log=0;
    1

  3. 重新设置慢日志文件名

    mysql> set global slow_query_log_file=’/home/bdsc/mysql/logs/mysql-slownew.log’;
    1

  4. 重新开启慢日志

    mysql> set global slow_query_log=1;
    1

  5. 查看慢日志存储目录

    [root@xxx logs]# ll
total 5112388
-rw-r----- 1 bdsc bdsc 3771060 Jul 20 16:49 mysql-error.log
-rw-r----- 1 bdsc bdsc 5231301707 Jul 19 00:00 mysql-slow.log
-rw-r----- 1 bdsc bdsc 205 Jul 20 16:51 mysql-slownew.log
    1
    2
    3
    4
    5

  6. 验证慢日志存储是否正确

    mysql> select sleep(10);
[root@xxx logs]# tail -fn 10 mysql-slownew.log
    1
    2

  7. 删除原来的大慢日志文件

    [root@xxx logs]# rm -rf mysql-slow.log
    1
